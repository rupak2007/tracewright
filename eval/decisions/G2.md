| Field | Value |
|---|---|
| Status | **Not run** |

## Why it was not run

G2 is decided on narratives for at least 30 incidents of the `test` split, rated blind by at least 3 people.
None of that exists:

* `python -m eval.splits report`: 10/27 corpus requirements met. `python -m eval.run_llm --split test` refuses to
  run until all 27 are, and the benign `test` runs would produce only the beacon false positives of untuned
  detectors, not attack incidents, so even a run would not measure what an analyst needs the narrative for.
* No language model was run against any incident in this repository (no local model is installed and no
  external provider was configured), so there is **no validator pass rate**, no audit sheet and no preference
  number. Nothing in this repository claims otherwise.
* No raters were recruited.

## What was built and verified (no model involved)

Implementation, tested with scripted providers only (`backend/tests/unit/test_validator.py`, `test_narrative.py`,
`test_llm_client.py`, `test_api_narrative.py`, `test_eval_llm.py`; the validator has 98% line coverage):

* pseudonymised evidence pack that never carries capture strings, with an injection fixture;
* the six-check validator, repair-once, rejected/unavailable fall back to the template, raw output stored, never shown;
* provider clients (`none` default, `ollama`, `openai_compatible`, `anthropic`), UI panel and report embedding of a
  validated narrative only;
* `eval/run_llm.py` (generation plus blinded sheets), `eval/score_llm.py` (metrics, rule, decision record).

## Consequences

* The default stays `LLM_PROVIDER=none`: the product is fully usable without a model and every narrative endpoint
  answers `unavailable` or `not_requested` with the template intact.
* S1 (grounded incident Q&A) is not built: it is allowed only if G2 passed with margin.
* To decide the gate: complete the corpus (`python -m eval.splits report`), configure a provider, run
  `python -m eval.run_llm --split test --run-id g2-test-1`, have at least 3 raters complete
  `eval/audit/g2-test-1/statements-<rater>.csv` and `pairs-<rater>.csv`, then
  `python -m eval.score_llm --run-id g2-test-1 --write-decision`. A negative result is documented, not rescued.
* Interpretations the PRD leaves open were fixed before any rating existed (`eval/REVISIONS.md` #8).
