# Gate G1 decision (anomaly scorer)

| Field | Value |
|---|---|
| Status | **Not run** |
| Decision | `ANOMALY_SCORER=off` (default); stage S5 ships implemented but switched off |
| Date | 2026-10-08 |
| Rule | PRD §11, applied verbatim by `eval.anomaly_metrics.decide_g1` |

## Why it was not run

The gate is evaluated on LAB-HOLDOUT test captures (families without a detector: ICMP tunnelling, slowloris,
SMB/RPC enumeration, reverse shell on a non-standard port) and BENIGN test captures. No LAB-HOLDOUT capture exists:
this repository generates no attack traffic and none has been supplied through the external-capture interface
(`python -m eval.splits report`: LAB-HOLDOUT families 0/3, test captures 0/8). Without held-out episodes there is
no precision@10, recall@10 or PR-AUC, no bootstrap difference, and therefore no number to apply the rule to.
`python -m eval.run_anomaly evaluate --split test` refuses to run until every corpus requirement is met, and on
`dev` it reports the held-out metrics as "not measurable".

## What was done instead (BENIGN dev only)

Calibration of the promotion cut-off (`python -m eval.run_anomaly calibrate`, results in
`eval/results/anomaly-calibration-dev-v1/`): runs b02, b04, b05, 37 pooled rule-unexplained windows, giving
`robust_z` 1163.98 and `iforest` 0.6877 (each just above the highest benign score, since 1% of 37 allows no
exceedance). These are recorded in `config/anomaly.yaml` with `eval/REVISIONS.md` #7. No test capture was read, and no
window size or Isolation Forest hyperparameter was tuned (that needs LAB-HOLDOUT dev captures).

## Consequences

* The default stays `off`: nothing is promoted, no `UNEXPLAINED_ANOMALY` finding appears in a normal analysis.
* The product's own population rule (>= 100 rule-unexplained windows) would skip the stage on every current lab
  capture anyway (9, 4 and 24 unexplained windows on b02, b04, b05).
* When LAB-HOLDOUT captures are supplied and verified, run `python -m eval.run_anomaly evaluate --split dev`
  for window-size and hyperparameter tuning, then `--split test` once, and replace this file with the decision
  and the numbers. The default scorer must then match the decision. A negative result is documented, not rescued.
